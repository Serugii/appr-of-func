# ЛР №1 — Апроксимація функцій: інтерполяція Лагранжа та МНК (JavaScript)

Запуск: відкрийте `index.html` у браузері (збірка та сервер не потрібні).

## Структура
- `js/data.js` — набори на 5 (варіант 15), 10 і 20 точок
- `js/math.js` — поліном Лагранжа; МНК через QR-розклад Хаусхолдера (без нормальних рівнянь), x нормалізується до [−1; 1]
- `js/plot.js` — canvas: осі, сітка, легенда, адаптивність (DPR)
- `js/app.js` — стан, анімації, підказки, метрики
